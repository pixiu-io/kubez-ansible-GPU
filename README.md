# Kubez-ansible-GPU

`kubez-ansible-gpu` 是面向 **GPU** 场景定制的 [kubez-ansible](https://github.com/pixiu-io/kubez-ansible) 分支项目，用于在 GPU 服务器上快速部署 Kubernetes 集群及云原生应用。

![Build Status][build-url]
[![License][license-image]][license-url]

## 项目介绍

面向 **GPU** 场景定制。

其它场景请使用上游项目：[pixiu-io/kubez-ansible](https://github.com/pixiu-io/kubez-ansible)。
